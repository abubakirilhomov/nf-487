# Glass Weather: PWA-приложение погоды

Vite + Vanilla JS + Tailwind CSS v4 + DaisyUI v5 + GSAP + Swiper + vite-plugin-pwa.
Данные берутся из OpenWeatherMap.

## Запуск

```bash
npm install
cp .env.example .env      # вставь свой ключ в VITE_OWM_API_KEY
npm run dev               # http://localhost:5173
npm run build && npm run preview   # проверка PWA в продакшн-режиме
```

> Новый ключ OpenWeather активируется в течение ~2 часов. Пока он не заработал, API отвечает 401.

## Библиотеки

| Пакет | Зачем |
|---|---|
| `tailwindcss`, `@tailwindcss/vite` | утилитарные стили (v4, подключается плагином Vite) |
| `daisyui` | кнопки, спиннер загрузки, базовая тёмная тема |
| `gsap` | смена цветов темы, плавающие сферы, счётчик температуры, появление карточек, молнии |
| `swiper` | почасовой прогноз и карусель «Мои города» |
| `vite-plugin-pwa` | manifest, service worker (Workbox), офлайн-кэш API |

## Как это работает

- **Локация.** При запуске запрашивается геолокация. Название места берётся через reverse geocoding.
  Если доступ запрещён, показывается последний открытый город, а если его нет, то Ташкент (меняется в `config.js`).
- **Тема по погоде.** Код иконки OpenWeather (`01d`, `10n`…) превращается в ключ темы (`themes.js`), после чего
  GSAP плавно перекрашивает CSS-переменные `--bg1..3`, `--orb1..3`, `--fg`, а canvas переключает частицы.
- **Прогноз на неделю.** Бесплатный тариф даёт 5 дней (шаг 3 часа, группируется по дням).
  Если поставить `VITE_OWM_ONECALL=true`, используется One Call 3.0: 8 дней, почасовой прогноз и УФ-индекс
  (нужна подписка «One Call by Call», первые 1000 запросов в день бесплатны).
- **Установка PWA.** В Chrome/Edge/Android приложение ловит `beforeinstallprompt` и показывает своё окно,
  а кнопка «Скачать» вызывает системный диалог установки. На iOS такого события нет, поэтому показывается подсказка
  «Поделиться → На экран Домой». Если окно закрыть, оно не появится 7 дней.
- **Офлайн.** Workbox кэширует файлы приложения и последние ответы API (NetworkFirst).

## Важно

- Геолокация и установка PWA работают только по **HTTPS** или на `localhost`.
  Чтобы проверить на телефоне в локальной сети, задеплой (Vercel/Netlify) или используй туннель.
- Ключ из `.env` попадает в собранный JS. Для OpenWeather это обычная практика, но лимиты и домены
  стоит ограничить в кабинете. Полностью спрятать ключ можно только через свой прокси-сервер.
